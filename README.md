# einfachNat Chat Overlay

Ein frei konfigurierbares Chat Overlay für OBS, Streamer.bot, Twitch und YouTube.

**Aktuelle Version: 1.1.0**

Der einfachste Weg zum eigenen Overlay ist der Generator auf:

https://einfachnat.ch/chat-overlay

## Warum dieses Projekt?

Ich bin keine klassische Softwareentwicklerin.

Ich bin Streamerin, kreativ, technisch neugierig und setze individuelle Lösungen um, die ich selbst gerne für meinen Stream hätte.

Nicht jeder möchte oder kann sich seinen eigenen Chat programmieren. Deshalb gibt es den einfachNat Chat Overlay Generator:

Einstellungen auswählen, Overlay herunterladen und in OBS verwenden.

Wenn dir etwas fehlt oder du eine Idee hast, melde dich gerne. Vielleicht wird daraus eine neue Funktion, von der am Ende alle profitieren.

## Funktionen

- Twitch Chat
- YouTube Chat
- Profilbilder
- Broadcaster-, Moderator-, Hauptmod- und VIP-Abzeichen
- individuelle Benutzerfarben
- anpassbare Chatblasen
- konfigurierbare Chatblasen-Deckkraft
- Filter für Chatbefehle
- Löschen von Nachrichten über Moderationsbefehle
- Twitch Kanalpunkte / Channel Points
- frei wählbarer Name der Kanalpunkte
- Zuschauerserien / Watch Streaks
- Feuerwerk und Sound für Zuschauerserien
- optionale Diagnosefunktionen für Streamer.bot-Events

## Verwendung

Für normale Nutzer ist keine Bearbeitung des Quellcodes notwendig.

Öffne einfach den Generator:

https://einfachnat.ch/chat-overlay

Stelle dein Overlay zusammen und lade die fertige HTML-Datei herunter.

Die HTML-Datei wird danach in OBS als lokale Browserquelle verwendet.
